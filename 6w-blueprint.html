Requirements

REQ-001 P0 proposed

Fast, normalized, zero-loss storage of link metadata, user organization/notes, AI summaries, and cross-OS reminders with tenant isolation.

Acceptance
  • All 11 tables, constraints, FK indexes, and RLS policies with (select auth.uid()) apply idempotently.
  • accept_invite(token) validates expiry/revocation/max_uses atomically; claim_due_reminders advances every_n_days in IANA timezone.

Links:

Shared Supabase JWT signature verification (backend/Login/) and strict ENV=development + ALLOW_DEV_AUTH_BYPASS gating for X-User-Id

REQ-002 P0 proposed

Closes unverified JWT & header bypass vulnerability across both Database/Login routes and existing Ai/router.py.

Acceptance
  • Invalid or tampered Bearer JWT returns HTTP 401; expired JWT returns HTTP 401.
  • X-User-Id without valid JWT returns HTTP 401 unless ENV=development and ALLOW_DEV_AUTH_BYPASS=true.

Links:

Multi-charset HTML detection (UTF-8/TIS-620/Windows-874/Shift_JIS/GBK), Unicode NFC normalization preserving tone marks, lossless full title/description TEXT, and 4-field FTS+trigram search

REQ-003 P0 proposed

Full non-truncated title and description across every script/language without mojibake, searchable sub-second across Thai, CJK, and English.

Acceptance

  • Search query matches substring phrases in title, description, note, and ai_summary across languages.
